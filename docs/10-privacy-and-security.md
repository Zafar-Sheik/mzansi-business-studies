# Privacy & security

- **No accounts.** Learners never sign up or log in.
- **No tracking.** There are no analytics, adverts or third-party scripts.
- **Progress stays on the device.** XP, completed lessons, quiz and exam marks, flashcard schedules and preferences are stored in the browser's `localStorage`. Clearing site data resets them.
- **Nothing typed is sent anywhere.** Practice answers, exam answers and essay ticks are checked in the browser.
- **No backend.** The site is static files. `/api/curriculum` is a read-only JSON feed of curriculum content with no learner data.
- **POPIA.** Because no personal information is collected, there is nothing to consent to, store or delete on a server.

Shared devices: each browser profile has its own progress. A learner can reset progress on the Progress page.
